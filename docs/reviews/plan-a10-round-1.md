## Disposition

A10 was rewritten rather than patched. The new design drops Cyrus's token-push endpoint and uses system-level helpers outside `~` that read a root-minted token file per call. That closes BLOCKING 1 and the stale-token note. `CYRUS_API_KEY` is dropped entirely, because the reviewer's security notes show that setting it is worse than leaving it unset; this reverses A8's extra condition. The remaining items are addressed as follows:
- BLOCKING 2: the no-argv rules are pinned.
- BLOCKING 3: the mirror uses the minter's read token; A8 and A9(h) are amended in place.
- BLOCKING 4: acceptance now includes the scope gate, a 404 on another repo, `GITHUB_TOKEN`/`CYRUS_API_KEY` absent from the service env, and a run with a missing key.
- The unit hardening, JWT claims, journal prefixes, runbook, `/etc/gitconfig` identity and Instabox size record are all included.

Re-submitted as round 2.
